## Repository Conventions

- `index.md` files provide expanded, CliffsNotes-style book summaries; they are not a conventional table of contents.
- Chapter notes are named `ChNN.md` or `Andersen_ChNN.md`.
- Associated figures are stored in each reference's `graphs/` directory and are linked from the relevant notes.
- `handoff.md` files contain working or processing context rather than reader-facing reference material.

## Use

These materials are reference notes and should be used alongside the original publications. Preserve the original authorship and applicable copyright when sharing or extending the library.
